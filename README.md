general
- open a web ui 
- search for watchable media using your rutracker account OR use magnet/.torrent
- filter by resolution, bitrate, seeds
- watch in realtime while downloading and transcoding

install
- run setup.bat
- u need normal chrome browser installed on your system
- run start.bat

docker
- install docker desktop
- run build-docker.bat
- put .tar on a server
- load docker
- run it via docker-compose.yml (set TP_DATA_DIR to your data folder)

cool features
- builtin vless config/subscription support
- cloudflare bypass
- history page for all torrents (even magnet and .torrent ones)
- persistent episode, watch progress, audio track, quality, volume
